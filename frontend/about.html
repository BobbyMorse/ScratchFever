About ScratchFever

Operated by EVQ AGENTIC LLC

What is ScratchFever?

ScratchFever is an AI-native betting intelligence platform that tracks expected value (EV) across state lottery scratch ticket games. We pull publicly available prize odds data, run the math, and surface the games where the stated return is highest — so you can make informed decisions before you buy.

What is EVQ AGENTIC LLC?

EVQ AGENTIC LLC is the company behind ScratchFever and the EVQBET.com platform. We build AI-powered tools for lottery and betting intelligence, combining real-time data scraping, statistical analysis, and agentic AI workflows.

What does ScratchFever do?

We scrape publicly available lottery odds disclosures published by state lottery commissions, calculate expected value per dollar spent, and display the results in a filterable, sortable table. We also offer a retailer hunt feature to help you locate stores that may still carry specific games.

ScratchFever does not sell lottery tickets, does not operate any lottery games, and has no affiliation with any state lottery commission.

AI Disclosure

ScratchFever uses large language model (LLM) AI agents for several features including retailer phone outreach and inventory verification. AI-generated content is labeled where applicable. Users should independently verify any information before making purchasing decisions.

Why are some states missing from the EV rankings?

Every state lottery is required by law to publish prize odds — we cover them all in the dropdown. But a handful of states can't be included in EV rankings right now due to technical blockers on their websites. Here's the full breakdown:

State(s)Why it's missing from EV rankings
WY Wyoming does not sell traditional scratch-off lottery tickets.
KS Kansas sells eInstants (digital-only games) — no physical scratch-off tickets with publicly disclosed odds.
ND North Dakota does not publish prize odds for scratch-off games in a format we can access.
TN The Tennessee Lottery website blocks all automated data requests (403 Forbidden). We cannot retrieve prize data without a manual source.
OH The Ohio Lottery uses a proprietary authentication API on their site that actively blocks non-browser data access. Their prize data is public, but their tech stack makes it inaccessible to scrapers.
WA, OR, MO, WV, OK, SD These states use fully JavaScript-rendered single-page apps with no accessible data endpoints. Prize data is rendered client-side in a way that requires a logged-in browser session we can't replicate reliably.
IA The Iowa Lottery site uses legacy ASP.NET postback navigation — each page requires a form submission that can't be automated with standard tools.

We're actively working on workarounds for these states. If a state is listed above, it means the data exists — we just can't get to it yet.

Why do some states appear but have no EV score?

A few states publish partial prize data — enough to show games and top prizes, but not enough to compute a full expected value:

StateWhat's missing
PA The Pennsylvania Lottery website only publishes the top 6 prize tiers on their remaining-prizes page. A complete prize table (needed for EV) is available in PDF format but not in a machine-readable form. We show PA games with top-prize data but cannot compute full EV without the lower tiers.

When we solve these, EV will appear automatically — no action needed on your end.

How often is the data updated?

Game odds and prizes-remaining data is refreshed every hour from each state lottery's official website. The timestamp shown on each game card reflects when that state's data was last successfully pulled. Retailer location data is updated monthly.

Why doesn't ScratchFever cover every state's retailers?

Retailer locator tools vary wildly by state — some use open APIs, others use JavaScript-protected maps with no accessible data endpoint. We currently have retailer data for MA, AZ, NY, NJ, GA, CA, NH, CT, and IL, and are expanding to more states as we crack each site's locator format.

Is this data official?

All prize odds and remaining-prize counts come directly from each state lottery's official website. ScratchFever does not generate, estimate, or alter this data — we read what the state publishes and run the math. We are not affiliated with any state lottery commission.
